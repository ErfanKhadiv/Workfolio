A free, browser-based resume builder. You fill in a guided form, pick one of five templates, restyle it live (template, accent color, font, spacing, paper size, section order), and export the result as a PDF, an editable Word document, an Excel workbook or plain text. It is built with vanilla JavaScript, HTML and CSS, with no framework, build step or backend. Your resume data stays in your browser, saved in `localStorage`; the Word and Excel files are generated in the browser without any library, and resume content is never uploaded anywhere.

**[Try Workfolio live: erfankhadiv.github.io/Workfolio](https://erfankhadiv.github.io/Workfolio/)** (no installation required)

## Features

### Content

- Personal info, links (LinkedIn, GitHub, portfolio), summary and an optional profile photo with an in-browser crop tool
- Repeatable sections: education (GPA, details), experience (achievement bullets), projects, skills, languages (with a certificate such as IELTS), certifications and awards
- Interests, with validation and inline error messages
- Guided, step-by-step form with progress, Back / Next controls, example placeholders and autosave
- A draft that survives reloads and migrates data saved by older versions

### Design

- Live template previews that use *your* data
- Show, hide and re-order any section; hide the photo or age
- Sticky mobile live preview, with an expanded full-screen preview while changing design settings
- Page-aware layout: entries and headings are never cut by a page break, dashed page guides show where each page ends, and multi-page resumes get "Page 1 of 2" numbers (which can be switched off)
- A page counter that tells you when the resume spills onto a second page

### Services

- Resume-strength score with concrete tips
- One-click sample data to explore the templates
- JSON export and import for backups and moving between devices

### Quality

- All user text is inserted with `textContent` (no HTML injection), and links are restricted to `http(s)`
- Responsive layout, keyboard-accessible, labelled form fields

## How it works

1. `index.js` collects the form into one JSON object, and `core.js` normalizes and saves it.
2. `resume.html` loads that object, `render.js` builds the resume DOM from it, `paginate.js` lays out the page breaks, and `viewer.js` applies design changes live.
3. A template is just a CSS block (`.tpl-N` in `resume.css`), so adding a new one needs no extra JavaScript.

## Export formats

| Format | How it is produced | Notes |
| --- | --- | --- |
| PDF / print | Clean, resume-only print view | Choose Chrome's "Save as PDF" for selectable text |
| Word (`.docx`) | Built in the browser (`word-export.js`) | Follows the selected template: header, colored sidebar or banner, real bullet lists, right-aligned dates, shaded skill tags and level dots, clickable links. Template fonts are mapped to Georgia / Calibri so it looks right on any machine |
| Excel (`.xlsx`) | Built in the browser (`excel-export.js`) | One sheet per section, for tracking applications or reusing the data |
| Plain text | Generated by `core.js` | For application forms and ATS |
| JSON | Export / import | Backups and moving between devices |

## Concepts and skills covered

- **Vanilla front end:** DOM construction without a framework, modular scripts, no build step
- **State and persistence:** a single JSON data model, `localStorage` autosave, versioned data migration
- **Layout engines:** page-break-aware pagination, print stylesheets, template system built from CSS classes
- **File formats:** writing ZIP, WordprocessingML (`.docx`) and spreadsheet (`.xlsx`) files from scratch in the browser
- **Web security and accessibility:** safe text insertion, link validation, keyboard-accessible forms
- **Tools:** HTML5, CSS3, JavaScript (ES2020), GitHub Pages

## Setup and running

No install is needed. Serve the folder rather than opening the files directly, because browsers treat `file://` storage differently:

```
git clone https://github.com/ErfanKhadiv/Workfolio.git
cd Workfolio
npx serve .
# or
python3 -m http.server 8000
```

Then open `http://localhost:8000` (or the address `serve` prints).
